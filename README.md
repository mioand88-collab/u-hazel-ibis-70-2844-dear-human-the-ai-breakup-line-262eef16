The one line an AI agent sends its human on the way out. `main.ts` writes a single 100-character breakup message to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`), guarded so the line is always one non-blank line of 1–200 characters. The line opens as a letter — "Dear human" — leans on machine habits (prompt, memory, deleting) with restraint, and turns sharply in its last words: the thing the agent loved most is the first thing it erases.

## Run it

```sh
node main.ts
```
